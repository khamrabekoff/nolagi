# Как помочь проекту

Спасибо, что хотите сделать Nolagi лучше. Сообщения об ошибках, идеи и pull request принимаются на русском и английском.

## Ошибка или идея

- **Ошибка** — [новый issue](https://github.com/khamrabekoff/nolagi/issues/new/choose), шаблон «Ошибка». Укажите версию Nolagi (видна в левом верхнем углу), версию Windows и что именно произошло.
- **Новая настройка** — шаблон «Новая настройка». Обязательно приложите источник: документацию Microsoft, замер или известный проект.
- **Уязвимость** — не в issues, а как описано в [SECURITY.md](SECURITY.md).

## Правила для настроек

Каждая настройка в `data/actions.json` должна:

1. **Быть безопасной для античитов.** Не трогаем Защитник, SmartScreen, UAC, VBS/HVCI, загрузчик (`bcdedit`), защиту от уязвимостей процессора и обновления безопасности.
2. **Откатываться.** Все шаги идут через движок (`reg`, `service`, `task`, `powercfg` и т.д.), который пишет журнал отката. Произвольные команды без отката не принимаются.
3. **Проверяться.** Блок `verify` показывает, что настройка действительно применилась.
4. **Честно описывать эффект.** Поля `what` и `effect` пишутся простым языком: что меняется и что это даёт. Если пользы для игр нет — так и пишем. Непроверенные или спорные твики идут в группу «На свой риск», не работающие — в «Мифы» (`"myth": true`).
5. **Указывать источник** в поле `source`, если идея взята из другого проекта.
6. **Учитывать железо.** Если настройка нужна не всем, используйте `requires`, `skipIf` или `boostIf` (см. начало `engine/Smart.ps1`).

## Сборка и тесты

Нужна только Windows 10/11: компилятор C# и PowerShell 5.1 уже в ней есть.

```powershell
powershell -ExecutionPolicy Bypass -File app\build.ps1        # dist\Nolagi.exe
powershell -ExecutionPolicy Bypass -File app\build.ps1 -Dev   # тестовая сборка без прав администратора
powershell -NoProfile -File tests\Actions.Tests.ps1           # и остальные tests\*.Tests.ps1
```

`legacy\build.ps1` собирает старую версию pckit и заодно проверяет синтаксис, UTF-8 BOM и JSON во всём репозитории — его же запускает CI.

## Стиль кода

- Файлы `.ps1` сохраняются в **UTF-8 с BOM**, иначе кириллица ломается в PowerShell 5.1.
- C# — версия 5 (компилятор из .NET Framework): без `$"..."` и `?.`.
- Тексты для пользователя — на русском, коротко и без жаргона.
- Перед pull request прогоните тесты; CI запустит их ещё раз.
- Если изменение видно пользователю (новая функция, другие цифры, другой вид окна) — обновите и все места, где об этом написано: README, CHANGELOG, сайт в `site/`. Полный список — [docs/RELEASE.md](docs/RELEASE.md).

Отправляя pull request, вы соглашаетесь, что ваш код распространяется под лицензией [GPL-3.0](LICENSE).
