# Безопасность

Nolagi работает с правами администратора, поэтому к безопасности здесь особые требования.

## Как сообщить об уязвимости

**Не пишите об уязвимости в открытых issues.** Используйте закрытое сообщение: вкладка [Security → Report a vulnerability](https://github.com/khamrabekoff/nolagi/security/advisories/new) в этом репозитории. Опишите, что нашли и как это повторить. Ответ — в течение нескольких дней.

Поддерживается только [последняя версия](https://github.com/khamrabekoff/nolagi/releases/latest): исправления выходят новой версией, и программа предлагает обновиться сама.

## Что уже сделано

- Программа ставится в `Program Files`, куда без прав администратора писать нельзя, — подменить exe обычной программой не получится.
- Скрипты движка распаковываются в `%ProgramData%\Nolagi` с правами «только администраторы» и сверяются по контрольной сумме при каждом запуске.
- Журнал отката хранится в `%ProgramData%\pckit` с теми же ограничениями: команды из него выполняются от администратора.
- Обновление скачивается только с сервера Nolagi по HTTPS и устанавливается, только если совпала контрольная сумма SHA-256.
- Nolagi не отключает защиту Windows: Защитник, SmartScreen, UAC, изоляцию ядра (VBS/HVCI), защиту от Spectre/Meltdown и обновления безопасности. Такие изменения не принимаются и в pull request.

## Цифровая подпись

У `Nolagi.exe` пока нет цифровой подписи, поэтому Windows SmartScreen может предупредить при первом запуске. Проверить, что файл не подменён, можно по SHA-256: он указан в описании каждого выпуска.

```powershell
Get-FileHash .\Nolagi.exe -Algorithm SHA256
```
